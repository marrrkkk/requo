# Multi-type email templates with canvas + inspector builder

Requo keeps one block-based email builder but supports three owner-customizable templates — Quote, Invoice, and Quote Follow-up — as separate nullable `businesses` columns (`quote_email_template`, `invoice_email_template`, `quote_follow_up_template`, `null` = defaults) rather than a single JSON library, so each type keeps its own block allowlist, merge tags, CTA rule (quote/follow-up exactly-one visible, invoice optional with no public link), validation schema, normalization, and renderer (`quote-email`, `invoice-email`, `quote-follow-up-email`) without migration breakage or cross-type leakage. The builder fixes drag reliability (whole-row draggable + always-visible grip + touch sensor + overlay for the editing block + drag never disabled by save pending) and layout overlap (thin hover gaps with no duplicate end slot, display-only sortable rows, text + style editing moved to a sticky side inspector, canvas + inspector grid stacking on mobile), preserves V2 quote configs and Pro `emailTemplates` gating (downgraded businesses keep stored JSON read-only and send defaults), and caps each template at 20 blocks.
